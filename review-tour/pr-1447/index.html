One notices list and one map pick in the open game

2 stops0 questions79 of 319 changed lines on the tour

The problem

The open game had four optional fields for two ideas: where the players are picking on the map (spawning, movingByCard, each with its own start and cancel call) and what the last step left to read (skippedEffects, drawnCards). The game log, the changes notice and the resolution dialog also took the raw GameState next to their view.

What changes

OpenGame.picking holds the one MapPick the map shows (spawn or moveByCard), set by startPick and ended by cancelPick, so a new kind of pick is one more kind and only one pick can be open. OpenGame.notices lists the step's OpenNotices, which noticeOf looks up and dismissNotice takes away by kind. GameLogSource carries the state the log reads, and PendingResolution the scenario and campaign the resolution dialog needs.
