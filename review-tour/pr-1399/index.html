Timing windows as event plus listener scope

A timing window is now an event, whose cards hear it, and optionally which card it must be about: { on, of?, filter? }. The three pairs of kinds that differed only in their listeners (turnEnds/eachTurnEnds, entered/investigatorEntered, defeated/enemyDefeated) become one event with a scope, and one matcher replaces the per-kind listener code. Card data doesn't change.
