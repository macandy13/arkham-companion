Reveal chaos tokens outside a skill test

2 stops1 question39 of 197 changed lines on the tour

The problem

Thirty-four player cards reveal chaos tokens outside a skill test, such as Hypnotic Gaze or Premonition. The app draws tokens only inside a test, so players who let the app draw had to reach for a physical bag for these cards.

What changes

The chaos bag page gets a Reveal tokens line: a count between − and +, and a button that draws that many from the bag and shows them until Put back. Outside a test every revealed token goes back into the bag, bless and curse too, so the draw changes nothing and, like the skill test's draw, is no game state.

Question for you

  1. The task asked for a RevealChaosTokens command with the seeded random. Since the tokens never leave the bag, the command would produce no event, so this is a pure draw like the skill test's, with the app's Math.random. Fine?

    Concerns stop 1. Picked: Pure draw, no command.
