One Selector for picked references

4 stops2 questions72 of 669 changed lines on the tour

The problem

Six references stood for "one of several, picked when there are more": the nearest enemy, an enemy, a location to move to, the location with the most tokens, the nearest location and an investigator. Each was its own kind of reference with its own candidate code, its own decision id and prompt, so a new card like "the location with the fewest clues" needed a seventh.

What changes

One picked reference, a Selector: the candidates of an each… reference (among), minus what except names, with best only those that measure the most or fewest (tokens, or connections from you), picked by the lead or by you. The six factories now build one, so card data is unchanged; one resolver lists the candidates and one helper asks the decision.

Questions for you

  1. The decisions now share the id pick:<card>, and "Which of the nearest enemies?" became "Which enemy does [card] affect?". Fine, or keep the old prompt for nearest enemies?

    Picked: One id and the enemy prompt: the options only show the nearest ones anyway..

  2. "The nearest enemy" now counts connections from you to the enemy, as the nearest location already did; before, it counted along the enemy's way to you. This differs only over one-way connections (The Devourer Below).

    Picked: From you: the rules define nearest as what can be reached in the fewest connections, and the rules check agrees..

  • Card data stays as it was.

    nearestEnemy({ trait: trait('Cultist') })

  best: { measure: { kind: 'distance' }, extreme: 'fewest' }, chooser: 'lead' }

  • Equally near cultists still go to the lead, and a one-way connection counts from you.

    Checked by packages/engine/src/triggers.test.ts › doom on the nearest Cultist enemy, or a search for one › counts a one-way connection from alice: the cultist she can reach in 1 gets the doom

  • Locked Door still attaches to the location with the most clues and no copy.

    Checked by packages/engine/src/attachment_targets.test.ts › a treachery that attaches to the location with the most clues (Locked Door) › attaches to the hall when the study already has a copy
