State the problem first and write the tour in plain sentences

A tour can now state the problem, and the page shows it first, followed by what changes. The writing rules in the coding guidelines now ask for concise text in whole sentences, describing the game or app effect before naming any code, with a before-and-after example. The template, CLAUDE.md and both reviewers check for the same thing.
