One way to change the game from the screen

2 stops1 question171 of 1177 changed lines on the tour

The problem

The play screen's GameActions had about 50 methods. Most were one-line wrappers around a single engine command, and several concepts had two or three names: evade and evadeEnemy, moveTo and moveByCard, testByCard next to investigate and fight, and four doom methods. Fixes took three routes (ManualAdjust, a real command, AdjustInvestigator), so whether a tap fired forced effects depended on which method a component happened to call.

What changes

GameActions is down to 19 methods. Move, investigate, fight, evade and engage take one How: as an action, as a free action, or { byCard: investigator }, for a card that has someone do it whoever's turn it is (Shortcut, In the Know, Marksmanship, Heroic Rescue). Everything else follows one rule. An effect the players carry out from card text is perform(...effects): engine commands that fire forced effects and can defeat. A mistake they fix is correct(...adjustments): ManualAdjust, which fires nothing. adjustTokens stays the one mix, since a token stepper places added doom by rule.

Question for you

  1. Components now build the engine commands they perform ({ type: 'DamageEnemy', … }), so the screen names engine command types directly. The alternative is a web-side Effect union in the players' words, mapped to commands, which costs roughly the methods it replaces. Is the direct command use fine?
