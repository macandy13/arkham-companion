Show how we know the change works

The problem

The review page showed the code that changed, but nothing showed that it works. Tests are left out of the tour on purpose, so the reviewer had to trust them blindly or open them, which defeats the one-minute review.

What changes

A tour can now list a few things that work after the change. Each one is a plain sentence backed by one proof: the test that checks it, a short example of the API in use with its result, or a screenshot. The page shows them after the stops under "How we know it works".

1Format

A claim and its proof

Each piece of evidence is a sentence plus at least one of a test name, a code example or a golden. A claim without any proof is rejected, so the check fails instead of showing an empty promise.
