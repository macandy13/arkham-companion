Split the header, the location tile and the investigator bar into one file per part

2 stops0 questions1354 of 3429 changed lines on the tour

The problem

The header, the location tile and the investigator bar were 780 to 830 lines each, holding a dozen inner components between them (agenda, act, scenario card, pawn, enemy token, counters, skills), so a reader scrolled to find one part and two changes to different parts collided.

What changes

Each inner part moves to its own file in the same folder, verbatim: a script compared the moved lines with the old files, and only imports, export keywords and Prettier's wrapping differ. GameHeader is now 63 lines, InvestigatorBar 100, LocationTile 509. No behaviour change, and no golden changed.
