Every command a card asks for carries its source

3 stops0 questions131 of 328 changed lines on the tour

The problem

Only twelve command types could carry the card that asked for them (source), and withSource kept a list of them that every new command had to join; five handlers read cmd.source to decide whether to refuse a command with nothing to do or do what they can.

What changes

Any command may now name the card that asked for it, and resolveEffect stamps it on whatever it produces, without a list. Handlers no longer read the field: handle tells each one whether its command is strict (sent without a card), and the lenient ones branch on that.
