Split abilities.ts by part, trim unused public exports

1 stop0 questions16 of 7387 changed lines on the tour

The problem

Writing a card meant scrolling a 3,600-line file where the factories scenarios use (whenRevealed, takeHorror) sit between the engine's own resolver and window matching. The engine's index also exported runtime helpers no other package imports, so its public surface was hard to read.

What changes

abilities/ has one file per part: types (Ability, TimingWindow, the references), dsl (the factories), windows (which cards an event opens a window for), resolve (abilitySteps, resolveEffect), objectives (the thresholds the board shows). Layering runs one way: types has no sibling imports, dsl only imports types, resolve imports the rest. The engine index loses the exports knip finds unused outside the engine.

How we know it works

  • Nothing was lost or duplicated: the old file and the five new ones have the same 265 top-level declarations with the same bodies; only six helpers shared between files gained an export.

  • Behaviour is unchanged: every unit test passes as before.

    pnpm test  # 4796 passed | 165 skipped

That's the whole change.
