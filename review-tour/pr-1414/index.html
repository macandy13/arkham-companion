Card actions read the ability condition

3 stops0 questions58 of 486 changed lines on the tour

The problem

Card actions such as Lita Chantler's parley or the Smoke and Mirrors act's action had their own small condition language (ActionCondition), next to the AbilityCondition that every other ability reads. A new card action that needed, say, a count of investigators or a phase had to grow the private language instead of using what triggered abilities already have.

What changes

Card actions now take an AbilityCondition, read in the window of the action itself, which names the acting investigator as you(). The shared condition gains what actions needed: whose turn it is (turn) and combinations (allOf, anyOf, not), so every ability can use them. Whether an investigator controls Lita Chantler is no condition any more: the game can't know, so Umôrdhoth's action asks its taker.

New shared conditions

Whose turn it is and the three combinators join AbilityCondition. Every ability can now say "during your turn" or "if there are exactly 1 or 2 investigators and it is your turn".

Actions read the condition in their own window

An action's condition is read in a window that names the acting investigator and the card, so you() and self() mean the same as in a triggered ability.
