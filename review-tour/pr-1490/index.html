Drop gh's unsupported -c flag from the merge gate

1 stop0 questions5 of 5 changed lines on the tour

The problem

The merge gate's first real run, on #1489, failed with "unknown shorthand flag: 'c'" from gh api, so no PR gets a gate status.

What changes

The gate's API calls drop the flag. gh already prints one compact JSON object per line, which is the format the gate's CLI reads.
