Every rules claim links its test

4 stops2 questions44 of 767 changed lines on the tour

The problem

The rules pages describe what the app does, but until now only the hunter page said which tests check it. A reader couldn't tell which claims the app enforces and tests, and which it leaves to the players or doesn't test at all.

What changes

Each claim gets one line per test that proves it, in the format MA.4a set up, as a link to the test's line. The rules checker read every named test against its claim and the wrong ones were replaced. Claims no test covers are left without a line and filed as gaps, grouped by area.

Questions for you

  1. File the untested claims as one sub-issue per area, per page, or per claim?

    Concerns stop 1. Picked: One per area, each with a checklist per page: six issues (#1508–#1513) a Sonnet session can each finish, plus #1514 for the backtick titles, instead of about 20 per page or 60 per claim..

  2. Is a link whose line can drift a few lines, until the page is next edited, good enough?

    Concerns stop 3. Picked: Yes: the file is always right and the line close; a strict line check would make most engine PRs rewrite rules pages and conflict with each other..
