The Midnight Masks card tests play a PlayTable

1 stop0 questions2 of 616 changed lines on the tour

The problem

A scenario card test spelled out every step as a command literal ({ type: 'UseCardAction', investigatorId, cardId, action: 0 }) and threaded the state through execute and stateAfter, so the card's claim was buried under plumbing and read differently from the flow tests.

What changes

Scenario card tests play a PlayTable with its verbs (useCardAction, drawEncounterCard, resolveRevelation, resolveTest, rejectionOf for a refusal) and read the board back. A raw command stays in its command's own engine test, or goes through table.play where no verb exists. Files move over when a change touches them, starting with The Midnight Masks.

1Guidelines

The convention

Which verbs, when table.play is still right, and that older files move over as they are touched.

Scenario card tests drive the table with its verbs too (`useCardAction`, `drawEncounterCard`, `resolveRevelation`, `resolveTest`, `rejectionOf(() => table.…)` for a refusal); a raw command literal stays in that command's own engine test, or goes through `table.play` for a step no verb covers (a scenario decision's `answer(...)`, an attack a card deals). Older scenario tests move over when a change touches them (The Midnight Masks' `cards.test.ts` is an example).
