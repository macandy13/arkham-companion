# Setup

[Setting up the game](https://arkhamdb.com/rules#Appendix_III_Setting_Up_The_Game): choose investigators; in a campaign each starts with damage equal to their physical trauma and horror equal to their mental trauma; choose the lead investigator; shuffle decks; build the chaos bag from the campaign (or keep the previous scenario's bag); each investigator gains 5 resources and draws 5 cards with one optional mulligan (weaknesses drawn now are set aside, replaced, and shuffled back afterwards); then the scenario setup (locations, starting positions, set-aside cards, encounter deck); agenda and act decks in order with 1a on top; scenario reference card. There are no player windows during setup. [Surge](encounter-draws.md) still applies to cards drawn during setup. Setup's own placements and engagements are not game events, so no "after" ability fires for them (our reading; no rule says so), with one ruled exception: a forced "after it enters play" ability still triggers for an enemy spawned during setup ([FAQ, Acolyte](https://arkhamdb.com/card/01169): it gets its 1 doom), so the setup step places those tokens itself.
