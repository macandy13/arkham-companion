# Decisions

Where the players must choose, or the engine needs an answer it cannot know (a skill test result, a spawn location, "advance the agenda?"), it puts a [`Decision`](../../packages/engine/src/state.ts) into `pending`. Each option carries the commands it triggers, so outcomes are data; counts the players may adjust are written as `{ answer: 'damage' }` placeholders. Basic action tests name the action (`testKind`) and compute their consequences on the answer, so corrections made meanwhile count. Options are answered by readable name (`optionNamed`), so options that pick a card are labelled with [`cardOptionLabels`](../../packages/engine/src/decisions.ts): the printed name, with the location added for copies of one card ("Ghoul Minion (Cellar)") and a number where that still leaves two alike. `ResolveDecision` runs the chosen option; while a decision is pending, only answers and `ManualAdjust` are allowed. Card data asks with `leadDecides` ("the lead investigator must decide") or `youMustEither` (the investigator the window names), an `AbilityChoice` whose options run ability effects; a part that touches player cards ("draw 2 cards") is only in the option's label, for the players to do at the table. Before an ability asks, a dry run of each option's commands drops the ones the engine would reject (spending a clue nobody has) or that would emit no event (healing nobody's damage); an option with no commands is done at the table and stays. A choice with no option left is not asked; a choice nested in a test's outcome is asked as it is. Skill tests ([`skill_tests.ts`](../../packages/engine/src/skill_tests.ts)) carry a suggestion from the printed skill, its lasting boost (`Investigator.skillBoosts`: what player cards in play add, such as an ally's +1 combat, which the players set with a `ManualAdjust` of kind `skillBoost` and which lasts until they change it), one player-entered modifier and the chaos tokens, but the answer stays the players' pass or fail.

## Extension points

- **Ask the players something:** return a `RequestDecision`; helpers for common shapes are in [`decisions.ts`](../../packages/engine/src/decisions.ts).
- **A new kind of question:** a `DecisionKind`, plus its debug sentence in [`describe_decision.ts`](../../packages/engine/src/describe_decision.ts). A new adjustable count is a name in `NAMED_AMOUNTS`.
- **A new skill-tested action:** a `SkillTestKind` and its resolver in `testedActionCommands`.
- **A board-dependent token value ("-X"):** a `tokenValues` entry in the scenario's `modifiers`.
