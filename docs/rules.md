# Rules summary

The game rules the engine implements, summarised in our own words so sessions don't have to search and re-read the Rules Reference. Each topic page links to its section on [ArkhamDB's copy of the Rules Reference](https://arkhamdb.com/rules); fetch that anchor when exact wording matters.

**Source and scope.** ArkhamDB mirrors the Chapter One Rules Reference with FAQ rulings up to v2.5. It does not cover the 2026 Core Set (Chapter Two). Where Chapter Two may differ, check the official 2026 rules and note the difference on the topic's page. Only scenario-side rules are listed; player-card rules (deckbuilding, slots, costs) are out of scope.

**Never paste rules text into these pages.** The Rules Reference is copyrighted. Keep entries as short paraphrases with an anchor link, and update an entry in the same PR that changes the rule in code.

**One page per topic.** Each topic below has its own page in [`rules/`](rules/), so PRs that touch different rules don't conflict. A PR edits its topic's page; this page changes only when a topic is added. Refer to topics by name (rules "Act and clues").
