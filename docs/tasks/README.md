# Tasks

The plan lives in GitHub issues, as a tree of sub-issues:

- **Milestone** – a parent issue with the `milestone` label: [M1](https://github.com/macandy13/arkham-companion/issues/261), [M1C](https://github.com/macandy13/arkham-companion/issues/262), [M1V](https://github.com/macandy13/arkham-companion/issues/263), [M2](https://github.com/macandy13/arkham-companion/issues/264) (done), [M3](https://github.com/macandy13/arkham-companion/issues/265), [M4](https://github.com/macandy13/arkham-companion/issues/266), [M5](https://github.com/macandy13/arkham-companion/issues/267), [M6](https://github.com/macandy13/arkham-companion/issues/268), [M7](https://github.com/macandy13/arkham-companion/issues/270), [M8](https://github.com/macandy13/arkham-companion/issues/271), [M9](https://github.com/macandy13/arkham-companion/issues/372). Its body says why the milestone exists and in which order its tasks go.
- **Task** – a sub-issue of its milestone, titled with its ID (`M5.3 The Midnight Masks`). The body is self-contained: a `**Model:** Opus · **Area:** engine` line, **Why**, **Benefit**, references and a checklist.
- **Slice** – a sub-issue of its task (`M1C.4c …`), one PR each. Follow-ups found while working are sub-issues too.

The milestone's sub-issue list is the task order. Finished tasks before 2026-10-24 and the Done notes written so far are archived in `done/`, one file per milestone.
